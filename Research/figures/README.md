# Figures for the research paper

Place your application screenshots in this folder using the filenames below.  
The LaTeX document uses `\IfFileExists` so it **compiles without images**; once you add files, they appear automatically on the next build.

| Filename | Suggested screenshot |
|----------|----------------------|
| `fig-map-overview.png` | Full map view: Zürich, Baumkataster trees, legend, filter rail |
| `fig-map-pick.png` | High-zoom tree/SR pick sheet or workflow panel open on map |
| `fig-desk-queue.png` | Service Requests page: search bar, SR cards in queue |
| `fig-desk-detail.png` | Desk detail panel with tabs (Overview / Inspection / etc.) |
| `fig-workflow-inspection.png` | Inspection form (desk or map panel) showing SR-centric labels |
| `fig-activities.png` | Activities tab with plan progress and open tasks |
| `fig-vision-model.pdf` or `.png` | Optional: your own conceptual diagram (or use the TikZ figure in the paper) |

**Tips:** PNG or PDF, width at least 1400px for clarity; crop sensitive demo data if sharing publicly.
